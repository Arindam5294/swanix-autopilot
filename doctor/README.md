# Repo Doctor

This repo only hosts the runner workflow (`.github/workflows/repo-doctor.yml`). The engine is the public repo
[Arindam5294/repo-doctor](https://github.com/Arindam5294/repo-doctor); the settings, reports and run logs live in
a separate private repo, so nothing personal is stored here and the public Actions log stays minimal.

Telegram: `/doctor` status · `/doctor now` · `/doctor off` / `/doctor on`.
